## 這一輪發現並修正的問題

- 未登入時每次載入頁面，瀏覽器主控台都會出現 `/api/auth/me` 的 401 → 新增未登入也回 200 的 `GET /api/auth/session` 給前端使用
- 大盤總覽表格檢視中，太長的公司名稱蓋到價格欄 → 名稱以省略號截斷，滑過顯示全名
- 模擬下單還沒選股票時，試算區一直顯示「試算中」→ 改成提示先選擇股票
- Swagger 沒有列出 401、403、409、429 回應 → 補上需要登入與登入相關的錯誤說明

## 未涵蓋

- **台股盤中**：本輪測試時台股已收盤，沒有在台股交易時段觀察大盤總覽每 30 秒更新；盤中邏輯由後端測試以模擬時間（10:15）驗證。美股盤中的 Finnhub 報價有實際取得

- 同時執行多個後端程序（失敗次數存在記憶體）與 HTTPS 部署（`SESSION_COOKIE_SECURE=true`）沒有測試
- 在開發伺服器操作大盤總覽時，瀏覽器主控台曾出現一次「404 (Not Found)」的資源載入錯誤；之後重新開啟大盤總覽、看盤頁與美股頁並記錄所有 4xx 回應，沒有再出現，原因未確定（推測是開發伺服器第一次編譯頁面時的暫時狀態）
