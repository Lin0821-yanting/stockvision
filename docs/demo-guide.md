# 課堂展示流程

建議展示前 10 分鐘先啟動前後端，確認 `http://localhost:8000/api/health` 回應 `"status": "ok"`。

| 時段 | 台股 | 美股 |
|---|---|---|
| 台北時間 09:00–13:30 | 盤中報價（每 10 秒更新、價格變動會閃爍） | 收盤 |
| 台北時間 21:30–04:00（冬令 22:30–05:00） | 收盤 | 有 Finnhub Key 時為盤中 |
| 其他時間 | 最近交易日收盤 | 最近交易日收盤 |

## 0. 啟動

```powershell
# 終端機 1
conda activate stockvision
cd backend
uvicorn app.main:app --reload --port 8000

# 終端機 2
cd frontend
npm run dev
```

## 1. 開啟 StockVision 網站並註冊

1. 開啟 http://localhost:3000：未登入時，投資總覽顯示功能介紹與熱門股票；側欄的模擬下單、投資組合、價格提醒旁有鎖頭。右上角燈號顯示台股、美股目前是否開盤
2. 按右上角「註冊」，輸入帳號（3–30 個英文字母、數字或底線）、顯示名稱與兩次密碼 → 「註冊並登入」。可以故意輸入不一致的確認密碼，展示表單驗證
3. 註冊後自動登入：右上角顯示名稱與通知鈴鐺，投資總覽出現自己的 NT$1,000,000 模擬帳戶
4. 說明安全設計：密碼以 scrypt 加鹽雜湊保存，登入狀態是 HttpOnly cookie（JavaScript 讀不到），資料庫只存 token 的 SHA-256

> 從第一版升級時，第一位註冊的帳號會接收原本單人模式的帳戶、交易、自選股與提醒。

## 2. 大盤總覽：台股與美股左右滑動

從側欄進入「大盤總覽」：

1. 台股頁：加權指數（盤中來自 TWSE MIS）與市值前 12 大公司（已發行普通股數 × 收盤價），每張卡片有價格、漲跌、市值與走勢小圖，滑過走勢圖顯示日期與收盤價
2. 在內容上左右滑動（觸控板、手機或滑鼠拖曳），或點上方「美股」：S&P 500、NASDAQ、道瓊（每日收盤）與美股市值前 12 大（GOOGL／GOOG 只列一次）
3. 切換 1 個月／1 年，走勢跟著改變；切到「表格」查看同一份資料的表格版本
4. 點任一張公司卡片，直接進入該股的看盤頁

## 3. 搜尋 2330 台積電

在上方搜尋框輸入「台積電」或「2330」，選擇「2330 台積電 上市」。說明：

- 報價卡片的「盤中／收盤」標籤、資料來源（TWSE MIS）、報價時間、資料日期與更新時間
- 開高低收、成交量（台股以張顯示）、前 20 日最低收盤

## 4. 顯示真實 API 的歷史股價

在「歷史走勢」切換 1 個月與 1 年，說明資料來自 FinMind `TaiwanStockPrice`（非即時的每日收盤）。切到「資料表」可以看到每日開高低收與漲跌幅。

## 5. 透過 Swagger UI 展示 Python FastAPI

開啟 http://localhost:8000/docs：

1. `GET /api/stocks/{symbol}` → Try it out → `2330` → Execute
2. `GET /api/market/overview` → `market=US` → Execute，看指數與美股大型股的資料
3. `GET /api/portfolio` → Execute，未登入回 401 `AUTH_REQUIRED`
4. `POST /api/auth/login` → 輸入剛才註冊的帳號密碼 → Execute；再執行一次 `GET /api/portfolio`，這次回 200（瀏覽器記住了 HttpOnly cookie）
5. 指出錯誤格式：`GET /api/stocks/{symbol}` 輸入 `9999` 會回 404 `SYMBOL_NOT_FOUND`

## 6. 用虛擬資金模擬買進

回到台積電頁面按「模擬下單」（或從側欄進入「模擬下單」）：

1. 股數先輸入 `1000`，畫面顯示「可用資金不足」且無法送出（後端檢查）
2. 改成 `100`，查看後端試算的參考價、金額與交易後現金
3. 按「確認買進」，確認對話框寫著「模擬成交，不代表真實市場價格或成交」→ 確認送出

## 7. 查看持股與損益

開啟「投資組合」：總資產、現金、持股市值、未實現與已實現損益、報酬率、持股配置、交易紀錄。重新整理頁面，資料仍然存在（SQLite）。

可再買一檔美股（例如 AAPL 5 股），說明以臺灣銀行 USD/TWD 匯率換算台幣，每筆交易都記錄匯率。

## 8. 設定低價提醒

在看盤頁按「設定提醒」：

1. 條件選「價格低於或等於（≤）目標價」，目標價輸入 900 → 建立，狀態為「監控中」
2. 再建立一個目標價高於目前價格的提醒（例如 3000）→ 條件已成立，右上角鈴鐺出現未讀通知，觸發紀錄記下觸發價格與來源
3. 說明「提醒的執行條件」：取得行情時同步檢查，後端運行期間背景排程每 60 秒檢查所有帳號的提醒（通知只會出現在提醒擁有者的帳號）；網站與後端都關閉時無法監控

## 9. 比較台積電與鴻海

開啟「股票比較」，加入 2330 與 2317（可再加 AAPL 示範台美混合比較）。

## 10. 說明資料由 Python Pandas 計算

指出比較頁上方的計算說明：以共同交易日對齊（inner join）、共同起始日 = 100、指數 = 當日收盤 ÷ 起始日收盤 × 100，以及「交易日（排除）」欄位。對應程式碼在 `backend/app/services/analytics.py` 的 `normalize_prices`。

## 11. 登出與資料隔離

1. 右上角選單 →「登出」：模擬下單、投資組合與價格提醒改顯示「請先登入」，看盤頁的按鈕變成「登入後加入自選」
2. 註冊第二個帳號：投資總覽是全新的 NT$1,000,000，看不到第一個帳號的自選股、交易與提醒
3. 再用第一個帳號登入（帳號不分大小寫），資料都還在；密碼輸錯時只會顯示「帳號或密碼錯誤」
